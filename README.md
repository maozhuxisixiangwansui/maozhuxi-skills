## 思想内核（共享底座）

两个 Skill 共同建立在毛泽东哲学体系之上：

### 一、唯物辩证法（《矛盾论》《辩证法唯物论》）
- **对立统一规律**：一切事物都是一分为二的，矛盾着的对立面又统一又斗争
- **矛盾普遍性与特殊性**：共性寓于个性，具体问题具体分析
- **主要矛盾与次要矛盾**：用全力找出主要矛盾，牵住牛鼻子
- **矛盾主要方面与次要方面**：决定事物性质，决定转化方向
- **内因与外因**：外因通过内因起作用
- **量变与质变**：积累到临界，促成转化
- **同一性与斗争性**：对立面相互依存又相互转化

### 二、认识论（《实践论》）
- 实践 → 感性认识 → 理性认识 → 再实践
- 实践是检验真理的唯一标准
- 从群众中来，到群众中去
- 没有调查就没有发言权

### 三、方法论
- 实事求是
- 调查研究
- 群众路线
- 战略上藐视，战术上重视
- 集中优势兵力，各个歼灭
- 你打你的，我打我的
- 持久战
- 农村包围城市（外围突破核心）
- 批评与自我批评

### 四、文艺思想（《在延安文艺座谈会上的讲话》）
- 文艺为人民
- 典型环境中的典型人物
- 革命的现实主义与革命的浪漫主义相结合
- 古为今用，洋为中用
- 百花齐放，推陈出新
- 两个标准：思想标准与艺术标准

## 调用方式

在 Claude Code 中：
```
/skill mao-coding       # 软件工程场景
/skill mao-fiction      # 小说创作场景
```

或在自然语言中直接说：
- "用毛泽东思想分析这段代码"
- "用矛盾论拆解这个 Bug"
- "用主席的文艺思想审视这部小说的立意"
